# Nile Packs Admin (simple)

Open: https://tarekhegazy77-svg.github.io/nile-packs/admin/login/

**Owner login**
- Email: `Tarekhegazy77@icloud.com`
- Password: the one you set (stored as a hash in the build — not in plaintext in git)

## What you can do
- **Products** — mark out of stock, restock, soft-remove / restore
- **Team** — owner can add staff (email + password) from inside the panel
- **Orders / sales** — overview of orders saved in this browser (empty until checkout records orders locally)

## Important
This simplified admin stores data in **this browser’s localStorage**. It does not need Cloudflare. Team members must use the same browser profile unless you later add a shared backend.
